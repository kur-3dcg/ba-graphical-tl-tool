# TLグラフィカルツール

ブルーアーカイブの総力戦・大決戦などで使うTL（EXスキルを使うタイミングの記録）を、生徒アイコン付きの画像に変換するWebツールです。

テキストで書いたTLを貼り付けるだけで、1920×1080のPNG画像と、Excel・スプレッドシート用のTSVを出力できます。

## 主な機能

- テキストのTLを、生徒アイコン付きの表画像に自動変換
- 行ごとにテキストと画像を並べて表示し、直す場所がすぐ分かる
- 未登録の生徒名や、制限時間・コスト上限を超えた指定を警告
- 置き換え（正規表現・テンプレート対応、元に戻す付き）で表記ゆれを一括修正
- 背景（白・透過）、文字サイズ、コスト表記、列見出し、区切り線などの画像設定
- 改ページの指定方法を選べる（行数指定 / `---` の位置だけ / 縦長1枚）
- 全ページをzipで一括保存、TSVのコピー・保存
- ボスのプリセット（制限時間・コスト上限）と、TLごとの生徒の別名設定

## TLの書き方

1行に「タイミング」「生徒」「コメント」を、スペース・タブ・全角スペースのどれかで区切って書きます。

```
開始SET ユウカ ホシノ ヒフミ キサキ
3:55 ユウカ 時間指定
6 ホシノ コスト指定
3:40 ユウカ→ホシノ→ヒフミ 先頭を指定時刻に使用し、後続は最速
NS着弾後 キサキ 条件指定
移行 第2フェーズ
⑤ リオ→Cホシノ リオでホシノをコピー
2:10.5 ウイ[ミカ] AUTO OFF
```

| 書き方 | 意味 |
|---|---|
| `3:55` / `6` / `⑤` / `5〜6` / `7付近` | 時刻・コストの指定 |
| `ユウカ→ホシノ` | 連続使用（2人目以降は最速） |
| `ウイ[ミカ]` | 対象指定（アイコンの右上に対象を表示） |
| `Cホシノ` | リオのコピー（Cバッジ付き） |
| `開始SET` で始まる行 | 開始時の編成 |
| `移行` で始まる行 | フェーズ見出し |
| `---` だけの行 | 改ページ |

詳しくはツール右上の「？ 書き方」を見てください。

## 開発

必要なもの: Node.js 18 以上

```bash
npm install
npm run dev        # 開発サーバー（http://localhost:5173）
npm run build      # 型チェック＋ビルド（dist/ に出力）
npm run typecheck  # 型チェックのみ
```

### 技術スタック

React 18 / TypeScript / Vite 5 / Tailwind CSS 3 / Canvas API / JSZip

### ディレクトリ構成

```
src/
  components/   UIコンポーネント
  lib/          TLの解析・画像描画・テキスト出力などの処理
data/
  ST.txt        STRIKERの生徒データ
  SP.txt        SPECIALの生徒データ
```

### 生徒データ

`data/ST.txt`・`data/SP.txt` は、UTF-8のタブ区切りで、1行目がヘッダーです。

```
image	名前
https://raw.githubusercontent.com/kur-3dcg/blue-archive-faceimage/main/images/sp/airi.png	アイリ
```

生徒画像はこのリポジトリには含めていません。`image` 列のURLから直接読み込みます。衣装違いの生徒は `ホシノ（水着）` のように、名前の後ろに（ ）で書きます。

## データの保存先

入力したTLや設定は、ブラウザの localStorage に保存されます。サーバーには送信しません。

## 注意

ブルーアーカイブの非公式ファンツールです。ゲーム内の画像・名称などの権利は、各権利者に帰属します。
